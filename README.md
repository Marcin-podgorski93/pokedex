# ⚛️ React + Vite — Starter Projekt

Ten projekt wykorzystuje **React** i **Vite** do budowy nowoczesnej aplikacji front-endowej z szybkim czasem ładowania i wygodnym środowiskiem deweloperskim.

---

## 🚀 Szybki start

### 1. Klonowanie repozytorium

```bash
git clone <URL-do-repozytorium>
cd <nazwa-katalogu>


2. Instalacja zależności

npm install
# lub
yarn install
# lub
pnpm install

3. Uruchomienie serwera deweloperskiego

npm run dev

Aplikacja będzie dostępna pod adresem: http://localhost:5173
```
